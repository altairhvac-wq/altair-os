# Foundation

Permanent documents that define Altair for the next decades.

## What belongs here

- Why Altair exists
- How Altair decides
- What quality bar Altair holds
- Who Altair is as a character
- The Altair creative world (Canon)

## What does not belong here

- Sprint status, feature inventories → `docs/product/`
- Session logs and operations guides → `docs/development/`
- Homepage storyboards, capture guides → `docs/marketing/`
- Closed validation screenshot passes → `docs/archive/`
- Prompt libraries, image IDs, creative checklists → `docs/creative/`
- Logo SVG production rules → `branding/BRAND_GUIDELINES.md`
- Product UI tokens/components → `docs/design/ALTAIR_DESIGN_FOUNDATION.md`
