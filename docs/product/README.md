# Product

Living product state for Altair OS: what exists, what is shipping, and what comes next.

## What belongs here

- Current product state and sprint scope
- Confirmed production inventory / product architecture notes
- Future experience-layer roadmap
- Stable pointer stubs for relocated design and development docs

## What does not belong here

- Company mission / principles / personality / creative world → `docs/foundation/`
- Product UI design constitution → `docs/design/`
- Session workflow and operations guides → `docs/development/`
- Marketing storyboards and capture guides → `docs/marketing/`
- Completed validation screenshot passes → `docs/archive/product/`
- Launch / QA checklists → `docs/reference/`
