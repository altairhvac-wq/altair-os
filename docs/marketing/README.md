# Marketing

Homepage narrative, marketing capture guidance, and living reference targets.

## What belongs here

- Homepage storyboard and positioning work
- Marketing screenshot capture guides
- Living reference targets for marketing surfaces

## What does not belong here

- Completed homepage visual validation passes → `docs/archive/marketing/`
- Creative world rules → `docs/foundation/ALTAIR_CANON.md`
- Prompt library / canon image library → `docs/creative/`
- Product UI design foundation → `docs/design/`
- Company mission / principles → `docs/foundation/`

## Authority

| Document | Responsibility |
|----------|----------------|
| [`ALTAIR_HOMEPAGE_STORYBOARD.md`](./ALTAIR_HOMEPAGE_STORYBOARD.md) | Homepage narrative blueprint |
| [`marketing-screenshot-capture-guide.md`](./marketing-screenshot-capture-guide.md) | Screenshot capture procedure |
| [`reference/`](./reference/) | Living marketing reference targets |
| `docs/archive/marketing/` | Closed visual validation artifacts |

Foundation and Canon govern brand truth. Storyboards implement narrative; they do not redefine mission or the creative world.

1. `docs/foundation/The_Altair_Mission.md`

4. `marketing-screenshot-capture-guide.md`
