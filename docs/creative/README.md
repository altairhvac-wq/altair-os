# Altair Creative Studio

Execution tools for Altair brand imagery, prompts, and creative production.

## Purpose folders

| Folder | Purpose |
|--------|---------|
| [`Brand/`](./Brand/) | Visual identity and creative guidance |
| [`Website/`](./Website/) | Website planning (reserved) |
| [`Creative/`](./Creative/) | Image, video, and storyboard assets; canon library |
| [`Prompts/`](./Prompts/) | Prompt collections and templates |

Company philosophy (mission, standard, personality, principles, Canon) lives in [`docs/foundation/`](../foundation/), not in this studio.

## What belongs here

- Visual design language
- Visual prompt library
- Canon image library index and category folders (`Creative/canon/`)
- Reserved slots: `Website/`, `Creative/reference-images/`, `Prompts/prompt-templates/`

## What does not belong here

- Company mission / principles / personality / standards → `docs/foundation/`
- The creative-world constitution → `docs/foundation/ALTAIR_CANON.md`
- Logo mark SVGs and locked logo guidelines → `/branding/` (`BRAND_GUIDELINES.md`)
- Product UI design tokens → `docs/design/ALTAIR_DESIGN_FOUNDATION.md`
- Homepage storyboards → `docs/marketing/`

## Authority

| Document | Responsibility |
|----------|----------------|
| [`../foundation/ALTAIR_CANON.md`](../foundation/ALTAIR_CANON.md) | Creative world (governs this folder) |
| [`Brand/ALTAIR_DESIGN_LANGUAGE.md`](./Brand/ALTAIR_DESIGN_LANGUAGE.md) | Working visual specification |
| [`Prompts/ALTAIR_VISUAL_PROMPT_LIBRARY.md`](./Prompts/ALTAIR_VISUAL_PROMPT_LIBRARY.md) | Prompt execution |
| [`Creative/CANON_IMAGE_LIBRARY.md`](./Creative/CANON_IMAGE_LIBRARY.md) | Approved image index |
| `/branding/BRAND_GUIDELINES.md` | Logo mark production rules |

If Design Language conflicts with Canon, Canon wins.

If Canon conflicts with foundation Mission / Standard / Personality / Principles on company philosophy, foundation wins — Canon should only describe the world.

## Recommended reading order

1. `docs/foundation/ALTAIR_CANON.md`
2. `Brand/ALTAIR_DESIGN_LANGUAGE.md`
3. `Prompts/ALTAIR_VISUAL_PROMPT_LIBRARY.md`
4. `Creative/CANON_IMAGE_LIBRARY.md`
5. Category folders under `Creative/canon/`
