# Design

Product UI design constitution and experience architecture for Altair OS.

This category is **Design / Foundation for the product interface**. Company philosophy and the creative world remain in [`docs/foundation/`](../foundation/). Marketing creative identity tools remain in [`docs/creative/`](../creative/).

## What belongs here

- Product UI design constitution (tokens, materials, components rules)
- Product visual philosophy (Horizon Intelligence / North Star)
- Experience architecture map
- Feature experience specifications (e.g., Altair Community)
- V2 component definitions (product-facing)

## What does not belong here

- Mission / principles / personality / Canon → `docs/foundation/`
- Creative photography / prompt libraries → `docs/creative/`
- Sprint status and production inventory → `docs/product/`
- Homepage storyboards → `docs/marketing/`
- Logo mark production assets → `/branding/`
