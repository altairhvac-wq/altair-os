# Archive

Historical and obsolete documentation retained for context. Do not treat archive contents as current product truth.

## Layout

| Folder | Contents |
|--------|----------|
| [`architecture/`](./architecture/) | Early architecture blueprint; pre-Supabase backend data map |
| [`marketing/`](./marketing/) | Completed homepage visual validation passes and capture artifacts |
| [`product/`](./product/) | Completed UI refinement / mission-briefing validation screenshots and phase notes |
| [`creative/`](./creative/) | Absorbed legacy brand-system relocation record |

## Rules

- Prefer living docs in `foundation/`, `product/`, `design/`, `development/`, `marketing/`, `creative/`, `reference/`.
- Do not delete archive material unless it is clearly unused and the team agrees.
- New ephemeral validation passes may start under `marketing/` or `product/` during active work, then move here when the pass closes.
- Capture scripts that still target `docs/marketing/homepage-*` may recreate those folders; move completed passes into `archive/marketing/` afterward.
